# 📝 Command-Line To-Do List

A simple **command-line To-Do List application built with Python**.
The application allows users to add, delete, mark tasks as completed, and view their tasks.

## 🚀 Features

* ➕ Add new tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as done
* 📋 List all tasks
* ❌ Exit the application
* 🔢 Simple menu-based interface

## 🛠️ Technologies Used

* **Python 3**
* Command Line / Terminal

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/To-Do-List.git
```

### 2. Open the project folder

```bash
cd To-Do-List
```

### 3. Run the program

```bash
python todo.py
```

## 💻 Usage

After running the program, you will see:

```text
===== TO-DO LIST =====
1. Add Task
2. Delete Task
3. Mark Task as Done
4. List Tasks
5. Exit
```

Choose an option by entering the corresponding number.

### Example

```text
Enter your choice: 1
Enter task: Complete Python assignment
Task added successfully!

Enter your choice: 4

Your Tasks:
1. Complete Python assignment - Not Done

Enter your choice: 3
Enter task number to mark as done: 1
Task marked as done!

Your Tasks:
1. Complete Python assignment - Done
```
